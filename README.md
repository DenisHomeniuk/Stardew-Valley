# Stardew-Valley
Manual Game QA тестування Save/Load системи гри Stardew Valley.

# 🎯 Область тестування

# Основні функції:
- ✅ Створення нового збереження
- 
- ✅ Автоматичне збереження
- 
- ✅ Завантаження існуючого збереження
- 
- ✅ Робота з декількома сейвами
- 
- ✅ Відновлення після перезапуску гри
- 
- ⚠️ Обробка пошкоджених файлів (виявлено проблеми)

# Технічні аспекти:
- Збереження прогресу гравця
- 
- Збереження стану світу
- 
- Збереження інвентарю та ресурсів
- 
- Робота з файловою системою
