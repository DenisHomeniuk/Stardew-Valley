# Project Overview: Save/Load System Testing for Stardew Valley

## 🎮 Про гру Stardew Valley

**Stardew Valley** — це симулятор сільського життя у відкритому світі, розроблений ConcernedApe (Eric Barone). Гра включає:
- Управління фермою
- Дослідження печер
- Взаємодію з персонажами міста
- Систему ремесла та виробництва
- Зміну пір року та погоди

Система збереження є критично важливою для ігрового процесу, оскільки:
- Гравець інвестує десятки годин у свій прогрес
- Багато дій є незворотними
- Різні ігрові системи взаємопов'язані

## 🎯 Мета проекту

**Основна мета:** Провести **демонстраційне/навчальне тестування** системи збереження/завантаження (Save/Load) у Stardew Valley з метою:

1. **Опанувати інструменти та процеси** Game QA на практиці
2. **Продемонструвати розуміння** повного циклу тестування ігор
3. **Навчитись працювати з** популярними QA інструментами та платформами
4. **Створити портфоліо-проект** для подальшого працевлаштування
5. **Відтворити реальний workflow** тестувальника ігор

### 📊 **Конкретні навички, що відпрацьовуються:**

1. **Створення тестової документації:**
   - Тест-плани в TestRail-стилі
   - Чек-листи у табличних форматах
   - Тест-кейси з покроковими інструкціями
   - Баг-репорти за стандартами індустрії

2. **Ведення QA процесів:**
   - Test case management
   - Defect lifecycle management
   - Test execution tracking
   - Regression testing procedures

3. **Робота з ігровими особливостями:**
   - Тестування систем збереження
   - Перевірка consistency геймплею
   - Boundary testing для ігрових механік
   - Exploratory testing в open-world іграх

4. **Звітність та комунікація:**
   - Daily/weekly test reports
   - Risk assessment документація
   - Рекомендації для розробників
   - Візуалізація результатів тестування

## 📊 Область тестування (Scope)

### Включено в тестування:
✅ **Основні функції збереження:**
- Створення нового збереження
- Автоматичне збереження після кожного дня
- Завантаження існуючого збереження

✅ **Управління збереженнями:**
- Робота з декількома сейвами
- Відображення інформації про сейви (ім'я, день, сезон)
- Порядок сортування сейвів

✅ **Відновлення даних:**
- Повне відновлення стану гри після завантаження
- Цілісність даних: інвентар, прогрес, взаємодії
- Координація персонажа та активності

✅ **Обробка помилок (Error Handling):**
- Пошкоджені файли збережень
- Відсутні файли
- Недостатньо місця на диску
- Аварійне завершення під час збереження

✅ **Крос-платформова стабільність:**
- Збереження між сесіями гри
- Вплив оновлень гри на збереження
- Сумісність зі Steam Cloud

### Не включено в тестування:
❌ **Мультиплеєр збереження** (кооперативний режим)
❌ **Модифіковані збереження** (моди)
❌ **Консольні версії** гри (тільки PC версія)
❌ **Автоматизоване тестування** (тільки ручне)


## 🔧 Технічні деталі

**Тестове середовище:**
- **ОС:** Windows 11 Home
- **Версія гри:** Stardew Valley 1.6.8+ 
- **Папка збережень:** `%AppData%\StardewValley\Saves\`

**Методологія тестування:**
- Чорно-сіре тестування (без доступу до коду)
- Позитивне та негативне тестування
- Boundary value analysis
- Error guessing technique
- Exploratory testing для edge cases
